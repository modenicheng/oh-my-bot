# client UI 设计令牌

科技感来自对齐、密度与克制的荧光，不靠渐变与圆角。

## 色板

| 令牌 | 值 | 用途 |
|---|---|---|
| `bg-0` | `#0a0e14` | 页面底 |
| `bg-1` | `#10141a` | 面板底 |
| `bg-2` | `#161b24` | 次级面板/输入底 |
| `line` | `#1f2733` | 1px 分隔线与容器描边 |
| `text` | `#d8dee9` | 正文 |
| `dim` | `#8b98a9` | 次级文字 |
| `neon-cyan` | `#22d3ee` | 主强调：链接、选中态、自机指示 |
| `neon-lime` | `#a3e635` | 成功 / 我方 / 上行 |
| `neon-magenta` | `#f472b6` | 搭档 / 强调 |
| `neon-red` | `#ff5c5c` | 敌方 / 危险 / 受击 |
| `neon-amber` | `#fbbf24` | 能量 / 警告 |

## 形状

- **默认 radius 0**：按钮、面板、输入框、代码块一律直角。
- 圆只留给语义圆形元素：雷达环、进度环、机器人本体渲染。

## 荧光纪律

- 荧光只用于**状态与数据高亮**：指示灯、选中态、图表数据线、关键数值。
- 文本永不发光；线条/指示器可用 `box-shadow: 0 0 8px <color>40%` 级微光。
- 同屏荧光色不超过 2 种主色，其余退回 `text`/`dim`。

## 字体

- UI：`Inter, system-ui, sans-serif`
- 数据/代码/时序：`ui-monospace, "JetBrains Mono", monospace`（HUD、计分板、日志、编辑器）

## 背景纹理

- 细网格（1px `line` @ 4% alpha，24px 网距）可作全局背景；扫描线动画仅用于加载/转段时刻。

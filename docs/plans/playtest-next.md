# 下一轮试玩改进

本轮侧栏、焦点、HUD、音效和发言先完成验证并原子提交，再推进本清单。所有改动按功能提交；不推送。以下是用户要求与验收方向，不表示已实现。

## 地图与玩法

- [ ] 增加地图形状变化。尝试网格化障碍拼接不规则掩体；保留出生点合法性、通路可达、锁区前后连通性与确定性生成。当前墙体契约是 AABB，优先评估多个网格矩形的组合，而非直接改变碰撞图形契约。
- [ ] 复核 `scan` 返回全图 Core 位置的行为，先阅读既有 ADR 和感知规则。当前 `snapshot.BuildObservation` 及 Round 2 契约明确让 Core/Uplink 全量可见，不能直接认定为 bug；如改变设计，同步脚本感知、快照、手册和测试。
- [ ] 确认机器人之间的碰撞和动量表现，能够被撞开/撞飞且速度会衰减。保留搭档软碰撞约束，参数必须通过实际试玩决定，避免持续滑动如台球。
- [ ] 给内环增加掩体，兼顾开放前的锁区边界、核心区路线、黑入点和开放后的可达性。
- [ ] 适当提高 Core 密度/刷新量，改善单人试玩找不到资源的体验；评估内外环分布与计分速度。
- [ ] 加入可用于单人测试的 AI Bot，明确加入/移除、数量、身份、队伍和房主控制，能展示移动、取资源、战斗与黑入。

## 编程体验

- [ ] 支持 TypeScript 脚本：评估客户端编译为 JS 后提交，保留错误定位、失败保留旧脚本和版本回执。运行时仍须遵守现有脚本沙盒契约。
- [ ] 编辑器背景更深、代码对比更高，与游戏配色一致，加入少量荧光效果；**保持现有编程字体**。此要求适用于代码编辑器，避免扩散到正文。
- [ ] 加入前缀补全，明确触发与自动补全规则，验证 API 成员、参数和片段补全，不破坏输入法或快捷键。
- [x] 确认 `say` 显示在机器人头顶的像素气泡，而不是侧边 banner。已纳入当前发言体验收尾；侧边保留击杀/Uplink 提示。

## 回放与观战

- [ ] 验证后端可以完整重放整场比赛：覆盖地图种子、版本、检查点、所有输入/脚本结果、手动发言、AI、阶段切换与最终计分，并验证从起点及中途检查点重演一致。当前手动发言已加入控制日志，但整场端到端审计仍待完成。
- [ ] 实现独立观战页面，支持自由拖拽地图和跟随任一 Bot，可独立子代理推进。复用地图绘制、相机和快照链路；目前玩家观察有 AOI 和墙遮挡，不能把不存在的观察者退化到 `(0,0)` 当作全图观战。设计真正的观战身份/全图只读数据流，确保不会发送操控输入；验证中途加入、掉线重连、切换跟随、目标离场、比赛结束和窄屏布局。

## 执行约定

视觉子任务使用 `glm-5.3-flash:max`，普通子任务使用 `glm-5.3:max`；疑难和最复杂审计、架构设计/搭建、复杂决策使用 `astra`。先核对现有设计，再调整公共契约；为行为和数值变化写有意义的回归测试，并通过真实浏览器试玩验证。

# 游戏规则

一局 8 分钟，最多 64 人，人人互为对手（FFA），只有一位随机搭档。基础规则全程不变——4:00 的转段只做一件事：打开中央区域。

## 对局结构

```
Room（房间）
 ├─ Warmup（热身场）：当前沿用正式模拟规则与时长，不累计 Session 积分
 └─ Match（对局）× N = Session（场次）：局散房不散，积分累计
     ├─ 0:00–4:00  OUTER_RING  外环争夺
     └─ 4:00–8:00  CORE_OPEN   核心解锁（只开放中央，不改其他规则）
```

## 地图：三环八扇区

地图是一个大圆，从外到内分三环，像靶纸：

| 环 | 范围（半径） | 里面有什么 |
|---|---|---|
| 外环 Outer | 55–80m | 8 个出生扇区（Sector），你出生在其中之一 |
| 中环 Mid | 30–55m | 6 个 Uplink，位置与扇区轴线错开 22.5°，防"出门即占桩" |
| 中央核心区 Core Zone | 30m 以内 | 4:00 前整片锁死；主 Uplink 随转段激活 |

补充几条地形规则：

- 人不满 64 时，玩家均分进 8 个扇区（比如 24 人 = 每扇区 3 人）。
- 参考尺寸 160×160m。墙段、掩体、资源刷新点的**布局**每局开局随机生成；三环骨架和扇区拓扑**永不变化**。
- 障碍只有实体墙：挡机器人、挡炮弹、挡视线，三者同一套判定。
- 机器人相撞会互相推开并产生短促击退，搭档也一样，但碰撞本身不扣血、不取消冲刺。没有移动输入时击退速度会快速衰减，不会一直滑行；墙体、未开放的核心区和场地边界仍不可穿越。
- 你的视野是半径 20m 且不穿墙；弹丸最大飞行距离也是 20m——**看得见的才打得到**，反过来你被打到时敌人也看得见你。

## 得分表

| 行为 | 得分 |
|---|---|
| 拾取 Core | +10（中央区更密；Mega Core +25） |
| 黑入 Uplink | +15（主 Uplink +25） |
| 击毁 | +25 |
| 助攻（击杀者的搭档自动获得） | +10 |
| 每次命中 | +1 |

资源分明显高于人头分——**这是抢资源抢据点的游戏，不是纯死斗**。死亡不掉分，惩罚就是 3 秒离场和对手趁机得分。

当前排行榜按总分降序排列，同分按机器人 ID 排序；尚未接入按 Uplink 得分、击毁数、存活时间逐级判胜的规则。

## Uplink：可反复争夺的黑入桩

Uplink（下称"桩"）是散布在中环和中央的得分设备，玩法是一个循环：

1. **靠近**：走到桩周围 2.5m 内（主桩 3m）。
2. **引导**：持续按住 `E` 或 `F`（脚本则每帧 `interact()`），顶满 **8 秒**。期间不能离开范围、不能开火。
3. **得分**：引导完成 +15（主桩 +25）。
4. **冷却**：你个人对**这根桩**进入 30 秒冷却——期间你不能再来黑它，但其他人（包括你的搭档）完全不受影响，可以立刻来抢。冷却跨死亡保留。

引导期间会发生什么、不会发生什么：

| 事件 | 引导会断吗 |
|---|---|
| 被子弹打 | **不断**——举盾硬顶是合法战术 |
| 松开按键 | 断 |
| 移出范围 | 断 |
| 开火 | 断（自己开枪打断自己） |
| 死亡 | 断 |

中断后进度清零、从头再来，但**不进冷却**——只有黑成功才启动 30 秒冷却。攻防博弈就在这里：防守方在你旁边开枪赶人打不断你，只等你先开火或先撤；双方都在赌对方先动。

中央主 Uplink 在 4:00 随转段激活，值 25 分。4:00 之前，中环的 6 根桩是外环打法的主要争夺点。

## 搭档（Partner）

- 开局随机配对，**整局固定**：互相打不着（弹丸互免），你击杀敌人时搭档自动 +10 助攻，反之亦然。
- **隔墙可见**：这是全场视野规则的唯一例外。搭档以描边显示，无视 20m 距离和墙体——他是你唯一可靠的全图信标。
- 除此之外全场无队伍概念，搭档之外人人可伤。
- 奇数人数时会有一名玩家没有搭档，脚本里 `partner()` 返回 `null`。

## 死亡、复活与无敌

- 死亡 → **3 秒**后在**你所属扇区**的出生点复活，满血满能量（防止滚雪球）。
- 复活自带无敌，规则分三档：
  - **未操作时保留**：没有有效手操或脚本动作时保持无敌；仅位置不变并不足以保证无敌；
  - **操作开始倒计时**：瞄准、移动、切换辅助等有效操作后 4 秒解除，后续操作不刷新倒计时；
  - **开火或引导立即解除**：无敌保护跑路，不保护输出。
- 实用结论：无敌 4 秒够你跑出出生点的被狙范围；但无敌期没有输出收益，别指望顶着无敌打人。需要等待时应停止有效输入；已运行的脚本也可能触发倒计时。

## 击毁与命中

- 血量 100，每发子弹伤害 12——大约 9 发击毁一人。命中一次 +1 分。
- 击毁 +25 归击杀者，其搭档助攻 +10。
- 冲刺无无敌帧；护盾减伤 65% 但期间不能开火。防守还是进攻，窗口自己把握。

# 操作与控制仲裁

这一页面向手操玩家，讲两件事：基本操作，以及一个很多人困惑的问题——**当你开着辅助（或脚本）时，"人和程序同时开车，谁说了算？"**

## 基本操作

桌面键鼠，网页直接玩：

| 按键 | 功能 | 要点 |
|---|---|---|
| `W` `A` `S` `D` | 全向移动 | 底盘没有"车头"概念，八方向随便走；斜着蹭墙会沿墙滑，正面撞墙会停 |
| 鼠标移动 | 炮塔瞄准 | 鼠标指哪炮口指哪；机器人或镜头移动时仍按当前鼠标位置更新瞄准 |
| 鼠标左键 | 开火 | 射击间隔 250ms，有效射程 16m；弹丸最远飞 20m，超过 16m 后散布增大 |
| `Shift` / 鼠标右键 | 按住冲刺 | 持续 16m/s、耗能 20/秒；任一仍按住就保持，全部释放即停；耗尽后需松开再按；与护盾互斥且没有无敌帧 |
| `Q` | 按住举盾 | 减伤 65%，期间不能开火、移速约八折 |
| `E` / `F` | 按住引导黑入 | 需在普通 Uplink 2.5m 内持续 8 秒（主桩为 3m）；松手、离圈、开火都会中断。桩周围的圆环和 HUD 同步显示进度 |
| `Space` / 小键盘 `Enter` | 驾驶辅助总开关 | 战场画布聚焦时可用；每局默认关闭，没有加载脚本或 Snippet 时不会自动增加行为 |
| `M` | 打开 / 收起文档 | 对局中切换右侧文档面板；大厅中打开 / 关闭全屏手册 |
| `C` | 打开 / 收起编辑器 | 对局中切换右侧代码编辑器面板 |
| `Enter` | 公开聊天 | 战场画布聚焦时打开聊天输入，再按 `Enter` 发送，`Esc` 取消；输入法组词中不会误发。仅存活时可用，无需开启辅助 |
| `Ctrl+Enter` / `Cmd+Enter` | 提交当前脚本 | 编辑器内使用，等同于点击“提交到机器人”；需处于已连接并完成同步的热身或正式对局 |

> 输入框、聊天、Snippet 参数或编辑器中打字不触发游戏快捷键；`Tab` 保留浏览器焦点导航，在代码区按编辑器规则处理。普通 `Enter` 打开/提交聊天，小键盘 `Enter` 只切换辅助。公开聊天与脚本的 `say()` 共享同一个 3 秒服务器冷却，消息显示为机器人头顶的像素气泡，随机器人移动，4 秒后消失。AI 面板是否可用取决于服务器配置；Pulse Scan 由脚本 API 调用。

## 实时观战

在大厅输入房间码后选择 **实时观战**，或从房间页在新标签页打开观战。观战连接只读、不占玩家名额，不会恢复玩家身份或发送操控；每个房间最多允许 64 个观众连接。

- 拖动地图平移，滚轮或工具栏按钮缩放；下拉框可跟随任意机器人。
- 画布聚焦后，方向键平移、`+`/`-` 缩放、`Home` 返回全图；`Esc` 退出观战。
- 支持中途加入、掉线重连、换局和结束后查看最终画面与得分。录像观战是另一入口，按已保存的检查点与事件近似重建，不是实时画面。

## 焦点与手操释放

手操是否生效由**战场画布的焦点**决定，与面板开关无关：

- 战场画布聚焦时（点击战场，或用 `Tab` 把焦点移到画布），WASD、鼠标、`Space` / 小键盘 `Enter` 辅助开关和普通 `Enter` 聊天都生效，工作台开着也一样。
- 焦点进入文档、编辑器或聊天输入时自动释放手操；游戏画面继续渲染，服务器模拟和已加载脚本继续运行。
- 打开 **文档（M）** 或 **编辑器（C）** 时焦点自动移入对应面板；关闭全部面板后焦点回到战场画布。**返回战场** 会一次关闭两者并回到战场。
- 入口页和大厅的手册仍是全屏视图。

## 面板布局与拖拽

- 右侧栏中文档在上、编辑器在下，只打开一个时占满侧栏。
- 侧栏宽度与文档/编辑器的上下分栏位置都可用分隔柄拖拽；分隔柄支持键盘操作：方向键微调，`Home` / `End` 直接到两端。尺寸保存在当前浏览器，刷新后沿用。
- 浏览器宽度不超过 760px 时，侧栏覆盖战场，仍可使用 **返回战场**。

编辑器中的 **辅助 ON/OFF** 按钮独立于“提交到机器人”。提交成功不会自动开启辅助。代码检查、草稿恢复和提交限制见[写第一个 Bot](../code/bot-scripting.md)。

## 驾驶辅助总开关（Space / 小键盘 Enter）

每局开局，辅助默认关闭。已加载 Bot Script 或 Snippet 时，可在编辑器点击辅助按钮，或在战场画布聚焦时按 `Space` / 小键盘 `Enter`：

1. 辅助关闭时：开启辅助，清除人工接管。
2. 辅助开启且有人工接管时：只把接管轴交回脚本，辅助保持开启。
3. 辅助开启且没有人工接管时：关闭辅助。

- 状态**持久保留**：不会因为你把手离开键盘就自动交还控制权，也不会在重连后丢失（服务器帮你记着）。
- 编辑器的辅助按钮随服务器快照同步，HUD 显示移动、瞄准、开火、技能四轴的控制来源和人工接管状态。
- 加载成功与开启辅助是两步操作，提交不会改变辅助开关。面板开着同样可以手操，把焦点移回战场画布即可。

## 分轴仲裁：人和程序怎么并存

这是本游戏最核心的一条规则，值得讲透。

如果已加载自动瞄准脚本，玩家仍能自己走路。控制权拆成**四根轴**：

```
移动轴  ——  WASD / 脚本的 move
炮塔轴  ——  鼠标 / 脚本的 aimAt
开火轴  ——  左键 / 脚本的 fire
技能轴  ——  Shift/右键/Q/E/F / 脚本的 dash、shield、interact
```

**仲裁规则只有一条：你的输入随时优先，按轴抢占。**

- 你按住 WASD 的那一瞬间，移动轴立刻归你。同一时刻，炮塔轴可能还归"自动瞄准"——**"人走位 + 程序瞄准"并存是本游戏的招牌体验**，不是 bug。
- 你没碰的轴继续归程序管。你碰了哪根轴，就抢走哪一根。
- **抢走的轴不自动归还**。人不会"因为 3 秒没动就把移动权还给脚本"——程序无法预判你是想挂机还是想卡走位。按一次 `Space` 即把人工接管轴交回脚本，无需先关再开。

这条规则同样适用于玩家 Bot Script 和官方 Snippet。最终来源会分别显示为脚本或 Snippet；写代码的玩家需要知道的对应细节（脚本感知不到手操状态、不要试图“检测人在开车就让位”）见[写第一个 Bot](../code/bot-scripting.md)。

## 技能状态显示与音效

- 右下角显示开火、冲刺、护盾、Uplink 与驾驶辅助的图标和键位。开火间隔由服务器同步；冲刺和护盾均为持续耗能技能，没有独立冷却。冲刺时显示“冲刺中”；能量不足、护盾挡住开火、Uplink 不可交互时，图标上会写明具体原因。
- 白色外圈表示护盾开着。开火、命中、撞墙都有短促音效；Core 出现与拾取各有独立音效；进入 Uplink 范围有低频提示，破解中有数据音，中断与成功音效不同。重连或快照重同步不会重播这些事件音效。
- 击毁敌人与 Uplink 破解成功时，左下角 HP / EN 上方弹出像素风横幅。
- 内环开放时，游戏区域顶部中央显示专属像素横幅，并播放逐级上升的开放音效。
- 本局剩余 30 秒时，计时器变红、放大一次并播放双次提示音；剩余 10 到 1 秒时，每秒放大并播放一次提示音。开启系统“减少动态效果”时保留红色与文字，取消跳动动画。
- 音效入口位于当前页面的工具栏，展开后可调音量或静音，设置保存在当前浏览器。离开对局或切到后台时持续音效自动停止。

## 断线与返回

- 短暂断线会立即停止本地输入并自动重试，横幅提供“立即重试”和“取消连接”。网络离线时暂停重试，恢复联网后继续。
- 服务器进程仍在时，用原房间和昵称恢复机器人身份、状态与辅助开关；收到完整快照后才恢复操作。
- 服务器重启会清空进行中的房间和对局，重新连上后回到大厅；无法继续原局。
- 浏览器失焦、切到后台或焦点进入文档、编辑器、聊天时会释放手操输入；已由脚本控制的动作仍按服务端规则运行。
- 重连或等待完整快照同步时禁止提交脚本。草稿在当前浏览器按房间码和昵称保存，刷新后可恢复；面板布局和文档路径从 URL 恢复，刷新或新局不会自动提交。

## 死亡与复活期间

- 阵亡后 **3 秒**复活，这段时间无法操作机器人。只要仍处于已连接并完成同步的热身或正式对局，仍可在编辑器提交脚本；对局结束后禁止提交。
- 复活点在**你所属扇区**的出生点，满血满能量。
- 复活自带无敌：没有有效输入时保留；有效操作后 4 秒解除，后续操作不刷新；开火或引导立即解除。已运行的脚本也可能触发倒计时，详见[游戏规则](game-rules.md)。

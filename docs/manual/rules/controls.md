# 操作与控制仲裁

这一页面向手操玩家，讲两件事：怎么按键，以及很多人第一次都会问的那句"**我开着辅助，人和程序同时开车，听谁的？**"

## 按键速查

桌面键鼠，浏览器直接玩：

| 按键 | 功能 | 要点 |
|---|---|---|
| `W` `A` `S` `D` | 移动 | 全向底盘，没有车头；斜着蹭墙会滑，正面撞墙会停 |
| 鼠标移动 | 瞄准 | 鼠标指哪炮口指哪（辅助脚本正在瞄准时改为 `R` 夺取，见下文） |
| 鼠标左键 | 开火 | 250ms 一发，有效射程 16m，弹丸最远 20m |
| `Shift` / 鼠标右键 | 按住冲刺 | 16 m/s，耗能 20/秒，松开即停，没有无敌帧 |
| `Q` | 按住举盾 | 减伤 65%，不能开火，移速约八折 |
| `E` / `F` | 按住黑入 | 桩周围 2.5m 内，主桩 3m，顶满 8 秒 |
| `R` | 夺回瞄准 | 炮塔轴被辅助脚本控制时，鼠标不再自动抢占炮塔；按 `R` 显式夺回 |
| `Space` / 小键盘 `Enter` | 辅助总开关 | 战场画布聚焦时可用，每局默认关闭 |
| `M` | 文档 | 对局中开侧栏文档面板，大厅里开全屏手册 |
| `C` | 编辑器 | 对局中开侧栏代码编辑器 |
| `Enter` | 公开发言 | 画布聚焦时打开聊天，再按 `Enter` 发送，`Esc` 取消 |
| `Ctrl+Enter` / `Cmd+Enter` | 提交脚本 | 编辑器内使用，等同于点"提交到机器人" |

在输入框、聊天、Snippet 参数或编辑器里打字，不会触发游戏快捷键。`Tab` 照常做浏览器焦点导航。

公开发言和脚本的 `say()` 共用一条 3 秒服务器冷却。消息显示成机器人头顶的像素气泡，跟着机器人走，4 秒后消失。

## 焦点决定键鼠归谁

手操跟战场画布的焦点走，跟面板开不开无关：

- 画布拿到焦点（点一下战场，或按 `Tab` 切过去），WASD、鼠标、`Space`、`Enter` 全部生效，工作台开着也一样。
- 焦点进了文档、编辑器或聊天输入，键鼠改去打字，手操自动释放，但画面、服务器模拟和已加载脚本继续跑。
- 按 `M`、`C` 打开面板时焦点自动移进去；全部面板关掉后，焦点回到战场画布。
- **返回战场** 一次关掉文档和编辑器。

## 辅助总开关

每局开局，辅助默认关闭。已经加载了 Bot Script 或 Snippet 后，可以在编辑器里点 **辅助 ON/OFF**，也可以在战场画布聚焦时按 `Space` / 小键盘 `Enter`：

1. 辅助关着：打开辅助，清掉人工接管。
2. 辅助开着，且有人工接管的轴：这些轴交回脚本，辅助保持开着。
3. 辅助开着，没有人工接管：关闭辅助。

状态跟着玩家身份走，不掉线丢，也不会因为你松开键盘就自动交还。编辑器的辅助按钮跟服务器快照同步，HUD 右下角显示四根轴各自的来源。

提交成功和开启辅助是两件事。提交不会自动打开辅助。

## 分轴仲裁：人和程序怎么并存

这是全游戏最核心的一条规则，值得讲透。

控制权拆成四根独立的轴：

![四根控制轴：人一碰立刻抢占，按 Space 交还](../reference/images/diagrams/control-axes.png)

```
移动轴  ——  WASD / 脚本的 move、moveTo、navigateTo
炮塔轴  ——  鼠标（辅助瞄准时 R 夺回）/ 脚本的 aimAt
开火轴  ——  左键 / 脚本的 fire
技能轴  ——  Shift、右键、Q、E、F / 脚本的 dash、shield、interact
```

仲裁只有一条规则：**人的输入随时优先，按轴抢占**。

- 你按下 WASD 的那一刻，移动轴归你。同一时刻炮塔轴可能还归自动瞄准。"人走位加程序瞄准"是这个游戏的招牌体验，不是 bug。
- 你没碰的轴，继续归程序。
- **抢走的轴不会自动归还。** 程序判断不了你是想挂机还是想卡位，所以只有你按一次 `Space`，接管轴才交回去，不用先关再开。

这条规则对玩家写的 Bot Script 和官方 Snippet 一视同仁。写代码的人要知道的细节在[写第一个 Bot](../code/bot-scripting.md)：脚本感知不到手操状态，也不该尝试"检测到人在开车就让位"。

### 炮塔轴例外：辅助瞄准期间的 `R` 夺回

上面"人的输入随时优先"有一条例外：**炮塔轴正在被脚本或 Snippet 瞄准时，鼠标移动不再自动抢占炮塔轴**。这是给"开自瞄、但想自己点左键开火"的玩家设计的——否则每次点击附带的鼠标微动都会悄悄打断辅助瞄准，自瞄"莫名其妙就失效了"。

- 触发条件：辅助开启，且炮塔轴当前来源是脚本或官方 Snippet（比如自动瞄准开着），且你还没接管过炮塔轴。
- 此时移动鼠标：炮塔仍由脚本控制，HUD 会提示「辅助瞄准中 · 按 R 手动瞄准」。
- 按 `R`：炮塔轴立刻归你，之后鼠标照常瞄准；HUD 弹「手动瞄准 · Space 交回辅助」。
- 按 `Space` 交回辅助后，如果脚本重新接管炮塔轴，这条规则重新生效。
- 辅助关闭、或炮塔本来就归你（自己写的 aimAt 脚本没接管/辅助没开）时，鼠标瞄准照旧逐帧抢占，行为不变。
- 旧服务器（快照不含分轴来源字段）不启用这条例外，鼠标行为与以前完全一致。

## 面板布局

- 右侧栏文档在上、编辑器在下；只开一个时占满整列。
- 侧栏宽度和上下分栏位置都能拖。分隔柄也吃键盘：方向键微调，`Home` / `End` 到两端。
- 尺寸存当前浏览器，刷新沿用。
- 浏览器宽度不超过 760px 时，侧栏盖住战场，**返回战场** 仍然可用。

## 实时观战

在大厅输入房间码后选 **实时观战**，也可以从房间页新开标签页进观战。

- 只读连接，不占玩家名额，不恢复身份，也不能操作。每个房间最多 64 个观众。
- 拖动平移，滚轮或工具栏按钮缩放，下拉框跟随任意机器人。
- 画布聚焦后，方向键平移，`+` / `-` 缩放，`Home` 回到全图，`Esc` 退出。
- 支持中途加入、掉线重连、换局，结束后能看到最终画面和得分。

录像观战是另一个入口，按保存的检查点和事件近似重建，不是实时画面。

## 状态显示与音效

- 右下角显示开火、冲刺、护盾、Uplink 与辅助的图标和键位。冲刺中、能量不足、护盾挡住开火、桩不可交互，图标上都会写明原因。
- 白色外圈表示护盾开着。开火、命中、撞墙都有短促音效；Core 出现和拾取各有声音；进入 Uplink 范围有低频提示，破解中有数据音，中断和成功的声音不同。
- 击毁敌人或破解成功，左下角 HP / EN 上方弹出像素横幅。
- 转段开门时，顶部中央显示专属横幅，配一段逐级升高的音效。
- 本局剩余 30 秒，计时器变红、放大一次并响两下；最后 10 秒每秒提示一次。系统开了"减少动态效果"，动画会停，红色和文字保留。
- 重连和快照重同步不会重播事件音效。音效开关在当前页面的工具栏，设置存浏览器。

## 断线与返回

- 短暂掉线会立刻停掉本地输入，自动重试；横幅上有"立即重试"和"取消连接"。网络断开时暂停重试，恢复联网后继续。
- 服务器还在，重连后回到原房间、原昵称、原辅助状态；收到完整快照后才恢复操作。
- 服务器重启会清空进行中的房间和对局，重连后回大厅，原局无法继续。
- 浏览器切到后台，或焦点进了文档、编辑器、聊天，手操输入释放；脚本控制的动作仍按服务器规则跑。
- 重连和等快照期间不能提交脚本。

## 死亡与复活期间

阵亡后等 3 秒复活，这段时间不能操作。只要还在已连接、已同步的热身或正式对局里，编辑器仍然能提交脚本；对局结束后不能提交。

复活点在你自己扇区的出生点，满血满能量，带无敌。无敌的解除规则见[游戏规则](game-rules.md)。

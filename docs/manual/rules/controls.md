# 操作与控制仲裁

这一页面向手操玩家，讲两件事：基本操作，以及一个很多人困惑的问题——**当你开着辅助（或脚本）时，"人和程序同时开车，谁说了算？"**

## 基本操作

桌面键鼠，网页直接玩：

| 按键 | 功能 | 要点 |
|---|---|---|
| `W` `A` `S` `D` | 全向移动 | 底盘没有"车头"概念，八方向随便走；斜着蹭墙会沿墙滑，正面撞墙会停 |
| 鼠标移动 | 炮塔瞄准 | 鼠标指哪炮口指哪；机器人或镜头移动时仍按当前鼠标位置更新瞄准 |
| 鼠标左键 | 开火 | 射击间隔 250ms，有效射程 16m；弹丸最远飞 20m，超过 16m 后散布增大 |
| `Shift` | 冲刺 | 按下触发一次，长按不会连冲；位移约 4.8m，耗能 20，冷却 2.5s，没有无敌帧 |
| `Q` | 按住举盾 | 减伤 65%，期间不能开火、移速约八折 |
| `E` / `F` | 按住引导黑入 | 需在普通 Uplink 2.5m 内持续 8 秒（主桩为 3m）；松手、离圈、开火都会中断。桩周围的圆环和 HUD 同步显示进度 |
| `Space` / `Enter` | 驾驶辅助总开关 | 每局默认关闭；没有加载脚本时不会自动增加行为 |
| `M` | 打开手册 / 再按返回 | 入口页和对局里都有标着 `M` 的按钮。看手册期间你的操作暂停，对局照常跑 |

> 输入框中打字不触发游戏快捷键；`Tab` 保留浏览器正常焦点导航。网页代码编辑器、Snippet、AI、喊话和 Pulse Scan 的操作入口尚未提供。

## 驾驶辅助总开关（Space）

每局开局，辅助默认关闭。已通过脚本接口加载 Bot 时，按 `Space`（备用 `Enter`）允许它接管相应动作；再按关闭、回到全手操。

- 状态**持久保留**：不会因为你把手离开键盘就自动交还控制权，也不会在重连后丢失（服务器帮你记着）。
- 右下角技能卡显示辅助 ON/OFF，以服务器状态为准；当前没有逐轴控制来源面板。

## 分轴仲裁：人和程序怎么并存

这是本游戏最核心的一条规则，值得讲透。

如果已加载自动瞄准脚本，玩家仍能自己走路。控制权拆成**四根轴**：

```
移动轴  ——  WASD / 脚本的 move
炮塔轴  ——  鼠标 / 脚本的 aimAt
开火轴  ——  左键 / 脚本的 fire
技能轴  ——  Shift/Q/E/F / 脚本的 dash、shield、interact
```

**仲裁规则只有一条：你的输入随时优先，按轴抢占。**

- 你按住 WASD 的那一瞬间，移动轴立刻归你。同一时刻，炮塔轴可能还归"自动瞄准"——**"人走位 + 程序瞄准"并存是本游戏的招牌体验**，不是 bug。
- 你没碰的轴继续归程序管。你碰了哪根轴，就抢走哪一根。
- **抢走的轴不自动归还**。人不会"因为 3 秒没动就把移动权还给脚本"——程序无法预判你是想挂机还是想卡走位。想整体交还，关闭后重新开启辅助。

这条规则适用于已加载的 Bot Script。写代码的玩家需要知道的对应细节（脚本感知不到手操状态、不要试图"检测人在开车就让位"）见[写第一个 Bot](../code/bot-scripting.md)。

## 技能状态显示与音效

- 右下角显示开火、冲刺、护盾、Uplink 与驾驶辅助的图标和键位。冲刺与开火的冷却由服务器同步；护盾是持续耗能技能，没有独立冷却。能量不足、护盾挡住开火、Uplink 不可交互时，图标上会写明具体原因。
- 白色外圈表示护盾开着。开火、命中、撞墙、Core 出现和拾取都有短促音效；进入 Uplink 范围有低频提示，破解中有数据音，中断与成功音效不同。
- 音效菜单可调音量或静音，设置保存在当前浏览器。离开对局或切到后台时持续音效自动停止。

## 断线与返回

- 短暂断线会立即停止本地输入并自动重试，横幅提供“立即重试”和“取消连接”。网络离线时暂停重试，恢复联网后继续。
- 服务器进程仍在时，用原房间和昵称恢复机器人身份、状态与辅助开关；收到完整快照后才恢复操作。
- 服务器重启会清空进行中的房间和对局，重新连上后回到大厅；无法继续原局。
- 浏览器失焦、切到后台或打开手册时会释放手操输入；已由脚本控制的动作仍按服务端规则运行。

## 死亡与复活期间

- 阵亡后 **3 秒**复活，这段时间无法操作机器人。服务器脚本接口仍可接受改码；当前网页没有编辑器入口。
- 复活点在**你所属扇区**的出生点，满血满能量。
- 复活自带无敌：没有有效输入时保留；有效操作后 4 秒解除，后续操作不刷新；开火或引导立即解除。已运行的脚本也可能触发倒计时，详见[游戏规则](game-rules.md)。

# 游戏规则

一局 8 分钟，64 人混战（FFA，人人互为对手），只有一位搭档。基础规则全程不变，4:00 转段只开放中央区域。

## 对局结构

```
Room（房间）
 ├─ Warmup（热身场）：无计分无死亡
 └─ Match（对局）×N = Session（场次）：局散房不散，积分累计
     ├─ 0:00–4:00  OUTER_RING  外环争夺
     └─ 4:00–8:00  CORE_OPEN   核心解锁（中央区开放，仅此而已）
```

## 地图：三环 + 八扇区

- **外环 Outer**（半径 55–80m）：8 个出生扇区（Sector），你出生在其中一个。
- **中环 Mid**（30–55m）：6 个 Uplink 分布于此，与扇区轴线错位 22.5°。
- **中央核心区 Core Zone**（<30m）：4:00 前锁闭；主 Uplink 随转段激活。
- 人数不满 64 时，玩家被均分到 8 个扇区（24 人 = 每扇区 3 人）。
- 参考尺寸 160×160m；墙段、掩体、刷新点布局由开局种子随机生成，骨架与拓扑永不变化。
- 障碍只有实体墙：挡机器人、挡炮弹、挡视线。视野 **20m**，弹丸最大飞行也是 20m——看得见才打得到。

## 得分表

| 行为 | 得分 |
|---|---|
| 拾取 Core | +10（中央区更密；Mega Core +25） |
| 黑入 Uplink | +15（主 Uplink +25） |
| 击毁 | +25 |
| 助攻（击杀者的搭档） | +10 |
| 每次命中 | +1 |

目标分权重显著高于击杀分——这是抢资源抢据点的游戏，不是纯死斗。**死亡不掉分**：惩罚就是 3s 离场和对手得分。平局判定：Uplink 得分 → 击毁数 → 存活时间 → 仍平则并列。

## Uplink 黑入

Uplink 是可反复争夺的得分设备，玩法循环：

1. **靠近**：进入 Uplink 周围 2.5m。
2. **引导**：按 `F`（或脚本 `interact()`）开始引导 **8s**，人不能离半径；受击不会打断（可以开盾硬抗），但开火会打断。
3. **得分**：引导完成 +15。
4. **个人冷却**：**每玩家每桩独立 30s**——你自己 30s 内不能再黑同一个桩，但其他人（包括搭档）不受影响，可以立刻来抢。

引导期间：**移出半径取消；受击不取消（可开盾硬黑）；开火取消；死亡取消**。防守方站在旁边开枪赶人时，"开盾硬黑"是合法博弈：他打不断你，只等你先动手或先撤。

中央主 Uplink 4:00 激活，+25。4:00 前 Uplink 是外环打法与中环拉扯的核心争议点。

## 搭档（Partner）

- 开局随机配对，整局固定：**不可互伤，共享助攻**（你击杀敌人，搭档 +10）。
- **隔墙可见**——这是视野规则的全场唯一例外：搭档以实体描边显示，且 `scan()` 结果恒带 `isPartner` 标记，不受 20m 视野限制。
- 全场无队伍概念，搭档之外人人可伤。奇数人数时的配对方案尚未定案——脚本层面 `partner()` 会返回 `null` 表示无搭档，届时以实机为准。

## 死亡、复活与无敌

- 死亡 → **3s** 后回**本扇区**出生点，满血满能量（防能量雪球）。
- 复活自带无敌：**挂机不解除**；做出任意操作后 **4s** 解除，且操作**不叠加刷新**（防出生点对狙：无敌期开一枪不会重置 4s 计时）。
- 实用含义：无敌 4s 够你跑出出生点周边被狙范围；但别指望无敌期输出收益——解除计时从你第一个操作起算。

## 击毁与命中

- HP 100，弹药伤害 12（约 9 发击毁），命中 +1 分。
- 击毁 +25 归击杀者，其搭档助攻 +10。
- Dash 无无敌帧；护盾减伤 65% 但不可开火。防守反击的窗口自己把握。

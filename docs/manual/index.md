# oh-my-bot 玩家手册

oh-my-bot 是一场最多 **64 人的机器人大乱斗**：每个人操控一台机器人，在圆形竞技场争夺资源、比拼得分，一局 8 分钟。无需编程，键盘鼠标就能参加。

## 当前可以怎么玩

| 玩法 | 当前状态 |
|---|---|
| **手操** | 网页可玩：移动、瞄准、射击、冲刺、举盾、黑入 Uplink |
| **Bot Script** | 网页 JS/TS 编辑器支持检查、补全和提交；TS 本地编译后由服务器运行与热更新 |
| **Snippet 驾驶辅助** | 八条官方模块可配置、查看源码，并与玩家代码按轴组合运行 |
| **AI Agent 改码** | 游戏内自然语言修改当前玩家代码；服务器配置模型后可热更 |

代码或 Snippet 收到服务器成功回执后，可用独立的 **辅助 ON/OFF** 按钮开启辅助，或在战场画布聚焦时按 `Space` / 小键盘 `Enter`。提交成功不会自动开启辅助；没有加载代码或 Snippet 时，开关不会自动产生行为。

## 第一次玩

1. **进房**：输入房间码，填昵称、挑颜色。第一个进入的人是房主。
2. **练习或开局**：房主可选择热身，也可直接开始正式对局。当前热身同样会受伤和死亡，具体限制见[进房前准备](start/prepare.md)。
3. **抢资源**：前 4 分钟在外环争夺 Core 与 Uplink；4:00 后中央核心区开放。
4. **看状态与文档**：左下角显示血量和能量，右下角显示技能键位、冷却和黑入进度；工作台提供 **文档**、**编辑器**、**辅助**和 **AI** 面板。
5. **看结算**：正式局结束后显示分数与称号。房间保留，房主可以再开下一局。

对局中的右侧工作台可显示文档/编辑器分栏，或整列显示辅助、AI 工具。手操跟随战场画布焦点：画布聚焦即手操，焦点进入文档、编辑器、参数输入或聊天则释放；模拟和程序继续运行。焦点与面板细节见[操作与控制仲裁](rules/controls.md)。大厅的手册仍以全屏打开。

## 核心概念速查

| 术语 | 含义 |
|---|---|
| Robot / Player | 场上的机器人 / 操控它的玩家 |
| Bot Script | 通过网页编辑器提交、由服务器运行的控制程序；JS 可直提，TS 在浏览器内编译为 JS 后提交 |
| Snippet | 可查看源码的官方 Bot Script 模块；与玩家代码同运行时、同仲裁 |
| Observation | 机器人视野内的机器人与炮弹，加上全图公开的 Core 和 Uplink；`scan()` 免费读取 |
| Pulse Scan | 消耗能量的脉冲请求；成功执行的帧将感知半径从 20m 扩为 32m，见 API 参考 |
| Ring / Sector | 地图三个同心环 / 外环八个出生扇区 |
| Core | 靠近后自动拾取的得分资源，同时回复能量；Mega Core 价值更高 |
| Uplink | 持续引导 8 秒后得分的设备，每个人对每根桩单独冷却 |
| Phase | OUTER_RING（0:00–4:00）与 CORE_OPEN（4:00–8:00） |
| Driving Assist | 允许已加载脚本控制未被玩家接管的动作轴，默认关闭 |
| Hot Swap | 提交新代码后更新脚本；加载失败保留旧版，运行异常不自动回滚 |
| AI Agent | 通过服务器模型代理自然语言修改当前玩家源码并热更 |
| Room / Session | 房间 / 服务端保存的连续多局累计积分；当前大厅尚无累计榜展示 |
| Warmup | 热身实例；当前沿用正式模拟时长和战斗规则，不计入 Session |
| Title | 正式对局结算时计算的个人称号，共 13 项 |

## 三条基本规则

1. **转段只开放中央**：4:00 后不会改变移动、伤害、能量和冷却数值。
2. **普通感知免费**：`scan()` 可每帧读取，不耗能量。
3. **手操优先**：操作某个动作轴后，该轴由玩家接管，松手不会自动交还给脚本。

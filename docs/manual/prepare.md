# 进房前准备

## 进房方式

oh-my-bot 没有公开匹配、没有账号。两种进法：

- **进房链接**：房主把链接发给你，点开即到昵称页。
- **房间码**：在入口页输入房主提供的房间码。

每个房间可容纳 1–64 人（1 人是房主单人试跑，合法）。唯一的开局方式是房主点"开始"。

## 昵称与配色

进房后只需填两样：

- **昵称**：自由填写，显示在机器人头顶与结算页。
- **配色**：给机器人选一个颜色，帮助搭档和对手在混战中认出你。

填完即入场，之后无需任何注册步骤。你与全场所有人都是对手（FFA），唯一的例外是系统为你随机分配的搭档。

## 热身场（Warmup）

房主"开始"之前，房间处于热身场状态：

- **任意漫游全图**：三环随便跑，提前熟悉墙体、掩体与刷新点布局。
- **编辑代码 / 配置 Snippet**：打开编辑器写 Bot Script 或调整 Snippet，改动即时生效。
- **无计分、无死亡**：放开试，这里的行为不进结算。

热身场复用与正式对局同一套权威模拟，你在热身场里试出的手感就是正式局的手感。注意：地图种子在房主点"开始"时才生成，正式局的墙体布局与热身场不同；三环骨架与八扇区拓扑则永不变化（详见[游戏规则](game-rules.md)）。

## 编辑器页面布局

对局与热身共用同一编辑器界面：

| 区域 | 内容 |
|---|---|
| 中央战场视图 | 实时渲染你的 Robot 周围 20m 视野内的战场 |
| 底部 / 侧边代码面板 | Bot Script 编辑器（Monaco），自带 lint 与类型检查 |
| Snippet 面板 | 六条官方驾驶辅助的开关与参数 |
| 顶栏 | 局时、阶段、HP / 能量条、分数、配额余量 |
| 手册入口 | 内置 Markdown 阅读器，即本手册 |

编辑器只负责改码和检查语法；想验证行为，直接在热身场跑，或对局中用 Hot Swap 热更提交。

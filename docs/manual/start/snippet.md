# Snippet 驾驶辅助（规划）

Snippet 计划提供无需编程的官方驾驶辅助，例如自动瞄准、拾取 Core 和紧急护盾。**当前客户端还没有 Snippet 面板，六条辅助也尚未实现。** 网页编辑器已支持编写和提交 Bot Script，但不会提供这些预设。编辑器中的 **辅助 ON/OFF** 按钮和战场上的 `Space` 都是脚本辅助总开关；没有加载脚本时，它们不会自动增加这些行为。

## 当前可用的辅助开关

- 每局默认关闭，以纯手操入场。
- 编辑器中可点 **辅助 ON/OFF**；关闭所有面板、返回战场后可按 `Space`（备用 `Enter`）。按钮状态随服务器快照同步，短暂断线重连后恢复。
- 在网页编辑器提交 Bot 并收到服务器成功回执后，打开辅助允许脚本控制未被玩家接管的动作轴。提交成功不会自动开启辅助。
- 玩家操作会逐轴接管，松手不自动交还；关闭后重新开启辅助才会整体交还。

打开文档或编辑器会释放手操输入，已加载脚本仍继续运行；只有关闭全部面板才恢复手操。完整按键和仲裁规则见[操作与控制仲裁](../rules/controls.md)，JavaScript 编写、提交与草稿恢复见[写第一个 Bot](../code/bot-scripting.md)。

## 规划的六条辅助

以下是设计目标，不能在当前客户端中勾选：

| Snippet | 预期行为 | 预期参数 |
|---|---|---|
| 自动瞄准 | 炮塔追踪敌人 | 提前量开关 |
| 自动开火 | 敌人进入射程后开火 | 射程阈值 |
| 自动拾取 | 移向附近 Core | 拾取半径 |
| 紧急护盾 | 低血时举盾 | HP 阈值 |
| 危险规避 | 躲避来袭炮弹 | 威胁半径 |
| 简单巡逻 | 沿路径点移动 | 路径点列表 |

这些辅助计划复用 Bot Script 和分轴仲裁。现阶段可阅读仓库中的六个脚本示例学习对应思路，示例清单见[API 总览](../reference/index.md)。

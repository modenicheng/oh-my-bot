# Snippet 驾驶辅助

不想写代码，又想让机器人自己动起来，就用 Snippet。

Snippet 是官方写好的 Bot Script 模块。它和你的代码跑在同一套沙箱里，同样受帧预算和分轴仲裁的限制，不是外挂。每条都能点开"查看源码"看个究竟。

## 三步开启

1. 对局里点侧栏 **辅助**，面板打开。
2. 勾模块、调参数，点 **应用配置**。
3. 点 **辅助 ON/OFF**，或在战场画布聚焦时按 `Space`，开关打开。

服务器先校验整份配置，通过才重新组装脚本。参数写错、组合失败，正在跑的配置和脚本原样不动。

## 六条官方模块

| Snippet | 干什么 | 参数 |
|---|---|---|
| 自动瞄准 | 炮塔直瞄最近的可见敌人（不预判提前量） | 无 |
| 紧急护盾 | 血低了举盾，回血后放下 | HP 阈值（0–100） |
| 危险规避 | 敌人或炮弹逼近时朝安全方向躲 | 威胁半径（2–20m） |
| 简单巡逻 | 按顺序走完路径点 | `x,y;x,y`，最多 8 点，坐标 ±80m |
| 全局 Core 拾取 | 用寻路走向全图最近的存活 Core，被抢走自动换目标 | 无 |
| 低血自动拾取血包 | 血低于阈值时寻路去最近可用血包 | HP 阈值（1–100） |

点开"查看源码"能看到真实代码。自动瞄准删繁就简之后，大概长这样：

```ts
function tick(bot) {
  const enemy = bot.nearestEnemy()
  if (enemy) bot.aimAt(enemy)
}
```

这正是一个 Snippet 的本质：一段 Bot Script。资源都靠机器人走过去接触自动拾取，没有 `pickup()` 这种 API。

自动瞄准只把炮口指向目标**当前位置**，不做速度预判——提前量外推是写代码的乐趣，官方模块不越俎代庖。什么时候开火、怎么算提前量，交给你的脚本或手指。

导航类模块用 `navigateTo`，也就是服务器算好的静态 A* 路径，会绕开墙、边界和 4:00 前锁着的中央区。它不躲移动中的机器人，也不预判炮弹。危险规避这类模块仍按自己的源码走直线。

## 和你自己的代码怎么并存

每个 tick 先跑你的代码，再按固定顺序跑启用的 Snippet。你在这一帧动过的轴，Snippet 不碰；你没动的轴，Snippet 可以接管。比如你写代码负责走位，自动瞄准就能替你转炮塔。

最终谁在控制每一根轴，服务器分轴记录。真用了 Snippet 的轴会显示成 Snippet 来源，也算进"古法编程"称号；只是勾上、没实际出力，不算。

## 总开关与人工接管

配置好模块还不够，要开总开关：编辑器里的 **辅助 ON/OFF**，或者战场画布聚焦时按 `Space`。小键盘 `Enter` 是无冲突的备用键，普通 `Enter` 还是聊天。

辅助关着，程序动作不生效。辅助开着，人照样随时抢轴；抢走的轴不会因为松手自动交还，再按一次总开关才交回去。完整规则见[操作与控制仲裁](../rules/controls.md)。

## 配置存在哪

Snippet 配置跟着房间里的玩家身份走：掉线重连、热身进正式、房主重开下一局，都会自动重新应用。主动离开房间后，服务器上的配置清掉，浏览器里的草稿还在，下次重新点应用就行。

# AI Agent

不想读 API 文档，也不想记语法，就用中文告诉 AI Agent 你想改什么，它替你改代码。

说一句"血低于 35 就停止开火，往最近的 Core 撤"，服务器拿这句话和你当前的源码一起去问已配置的模型。模型返回新脚本，走和手动提交完全一样的编译、加载、热更链路，立刻生效。

## 它能看到什么

只有你一个人的代码，外加面向 AI 的手册章节。看不到别人的源码，也绕不过 Bot API、感知范围、帧预算和控制仲裁。

模型密钥只存在服务器上，不下发浏览器，不写进对局记录，报错信息里也不会带出来。

## 怎么用

1. 进热身场或正式对局，打开侧栏 **AI**。
2. 用一句话说清你要的行为，比如"HP 低于 35 时停止开火，远离最近的敌人"。
3. 点 **发送**。同一个玩家一次只处理一条请求，没返回前按钮锁着。
4. 面板显示模型说明、错误和剩余额度。编译成功就自动热更；编译失败或版本冲突，旧脚本继续跑。
5. 想让程序动作真的生效，记得打开驾驶辅助总开关。

AI 改出来的代码大致是这个样子，逐字细节每次可能不同：

```ts
function tick(bot) {
  const low = bot.self.hp < 35
  const enemy = bot.nearestEnemy()
  if (enemy && !low) {
    bot.aimAt(enemy)
    bot.fire()
  }
  if (low) {
    const core = bot.nearestCore()
    if (core) bot.navigateTo(core)
  }
}
```

**一个要提前知道的坑**：协议不回传 AI 生成的完整源码，热更成功后不会自动盖掉编辑器里的草稿。想继续手改，先按实际效果决定怎么对齐你那份草稿。

## 额度

| 额度 | 默认值 |
|---|---|
| 每人每局提示轮次 | 20 轮 |
| 每人每局 token | 300k |
| 单局全场 token 护栏 | 2M |
| 全局并发 | 20 个请求 |
| 同一玩家并发 | 1 个请求 |

你发一条提示算一轮。token 按模型返回的实际用量记账。热身场和紧接其后的正式对局共用同一份额度；新开一轮热身，或者从空闲直接开新局，额度重新计算。全场护栏触顶后，本局所有玩家都不能再调用。

## 和手动提交抢版本

AI 请求处理期间，你仍然可以自己提交代码。服务器在请求发起时记下脚本版本，模型返回后只在版本没变时落地。你要是手快先提交了新版，或者另一个 AI 结果先落地，迟到的那个直接丢弃，绝不覆盖新版。

模型调用在房间锁外面跑，等网络不会卡住 60Hz 的对局。Snippet 和 AI 也能同时用：AI 只改你的源码，看不到官方 Snippet 的包装代码；落地后服务器再和现役 Snippet 配置重新组合。

## 服务器没开 AI 会怎样

面板会给一条定向提示，不会把你的话广播到聊天。部署的人需要打开 `config.yaml` 里的 `ai.enabled`，并在同目录 `.env` 或进程环境里设置 `DEEPSEEK_API_KEY`。配置方式见[部署指南](../../deploy.md)。

动作接口和脚本预算见[写第一个 Bot](../code/bot-scripting.md)；不想用 AI，也可以直接用 [Snippet 驾驶辅助](snippet.md)。

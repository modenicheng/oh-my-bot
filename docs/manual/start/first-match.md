# 你的第一局

这一页带你打完第一局手操——不写任何代码，只用键盘鼠标。规则细节都在[游戏规则](../rules/game-rules.md)，这里只讲"上场后该干什么"。

## 操作就五件事

| 按键 | 干什么 |
|---|---|
| `W` `A` `S` `D` | 移动。全向底盘，八个方向随便走，没有"车身朝向"的概念 |
| 鼠标移动 | 炮塔跟着鼠标指 |
| 鼠标左键 | 开火。射击间隔 250ms，建议在 16m 内交战，弹丸最远飞 20m |
| `Shift` | 冲刺：朝移动方向猛冲一小段，赶路用，不是无敌技 |
| `Q` | 按住举盾：少受 65% 伤害，但不能开火、走得慢 |

另外记住两个：`E` / `F` 按住可以对 Uplink 引导黑入（下面讲）；`Space` 是“驾驶辅助总开关”，没有加载脚本时不会自动增加行为。全部快捷键见[操作与控制仲裁](../rules/controls.md)。

需要查规则时，点顶部 **文档（M）** 或按 `M` 打开右侧文档；**编辑器**（`C`）可以单独展开，也可以与文档同时打开。打开面板时焦点移入面板；点回战场（或用 `Tab` 聚焦画布）即可继续手操，面板开着也一样，模拟和脚本照常运行。

## 这局的目标是什么

一局 8 分钟，得分高者胜。得分手段按性价比排序：

| 行为 | 得分 | 一句话点评 |
|---|---|---|
| 捡 Core | +10 | 走过去就自动捡，最稳分的来源 |
| 黑入 Uplink | +15 | 要站桩引导 8 秒，收益高风险也高 |
| 击毁敌人 | +25 | 一次性大额，但风险最大 |
| 每次命中 | +1 | 打中就有，零钱也是钱 |
| 助攻 | +10 | 你击杀敌人时你的搭档自动拿，反之亦然 |

看出来了吗？**捡 Core 的性价比远高于杀人**。这是抢资源的游戏，不是纯死斗。死亡不掉分——惩罚就是 3 秒离场和对面趁机得分。

## 第一局的推荐打法

1. **开局先抢 Core**。Core 是发光的资源点，走过去 0.6m 内自动拾取。中央区（地图中心 30m 内）Core 更密，但 4:00 前那里是锁着的，先在外环捡。
2. **别追着人打**。弹丸最远飞 20m，地图半径却有 80m——追人追不上，还被放风筝。看到人先想想：打得过吗？打不过就跑，跑不掉就举盾。
3. **看到 Uplink 桩可以试一次**。走到桩旁 2.5m 内，按住 `E` 或 `F` 不放，顶 8 秒就 +15。被打了别慌——挨打不打断引导，举着盾顶完就是你的。但**一旦你开了枪，引导立刻断**。
4. **4:00 转段后中央开放**，Core 变密、主 Uplink 激活（+25）。那时候再往中间挤。
5. **死了就当休息**。3 秒后你在自己扇区满血复活，还带几秒无敌——无敌期够你跑回安全区，别在无敌期开枪（一开枪无敌立刻消失）。

## 看不清远处是正常的

你的视野是**半径 20m、不穿实体墙**。搭档、Core 和 Uplink 是公开信息；普通敌人和炮弹只有进入视野才可见。所以：别在空地发呆，多利用墙体掩护，转角处减速。这是游戏设计，不是 bug。

打完第一局，去结算页看看 13 个称号花落谁家（"充能面包"颁给被击毁最多的人）。想试自动化玩法，可在下一次热身或正式对局中打开网页编辑器，按[写第一个 Bot](../code/bot-scripting.md)提交 JavaScript；收到成功回执后再单独开启辅助。草稿会保存在当前浏览器，刷新或新局都不会自动提交。[Snippet 驾驶辅助](snippet.md)仍在规划中。

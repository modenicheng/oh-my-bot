# 进房前准备

游戏无需注册账号或安装客户端，用桌面浏览器访问部署地址即可。

## 怎么进房

oh-my-bot 没有公开匹配。房主先选一串 **4–8 位大写字母或数字的房间码**，填入入口页并进入；第一个进入该房间的人自动成为房主。把房间码或带 `?room=房间码` 的页面链接发给其他人，他们填自己的昵称后加入。

一个房间最多 64 人，也可以由房主单人试跑。房主在大厅选择“热身场”或“开始对局”；游戏不会自动倒计时开局。

## 单人测试 Bot

房主可以在大厅点击 **添加 3 个测试 Bot**，再进入热身场或开始正式对局。开关只影响下一次装配的对局，不会在正在进行的场内增删机器人；关闭后下一场不再添加。刷新和重连会恢复房间配置。

这些是内置脚本机器人，不调用外部 AI 服务。它们会移动、拾取 Core、攻击可见敌人并尝试黑入 Uplink，遵守普通脚本感知和现有搭档规则，因此其中可能有你的搭档。真人辅助仍需自行开启。

测试 Bot 不占真人房间席位，也不增加大厅在线人数；开场时真人与 Bot 总数最多 64，余量不足时少加。Bot 会出现在当局结算和正式局日志中，但不进入房间累计积分。它们使用简单的绕行与脱困策略，不保证每条复杂掩体路线都能顺利通过，也不是高强度对手。

## 填写昵称和配色

| 项目 | 说明 |
|---|---|
| 昵称 | 1–16 个字符；同一标签页刷新会保留。房间内相同昵称的新连接会替换旧连接，请各用不同昵称 |
| 配色 | 从入口页色板选择，帮助在场上辨认机器人 |

填完点“进入房间”。短暂断线后页面自动重连，恢复同一房间和昵称；详情见[操作与控制仲裁](../rules/controls.md)。

## 热身场的当前行为

房主点击“热身场”后进入练习地图，仍可从右上角开始正式对局。正式开局会生成新地图，墙体布局不必与热身相同。

**当前热身复用正式模拟规则**：会受伤、死亡和复活，前 4 分钟中央仍锁定；拾取和击毁等事件照常产生，但不写正式对局日志，也不累计到 Session 积分。它目前还不是不限时、全图开放的练习模式：底层模拟在 8 分钟后停止，房主可点击“开始正式对局”进入新局。

可以练习 WASD、瞄准、开火、举盾与黑入，也可以按 `C` 或点 **编辑器** 编写 JavaScript 或 TypeScript，提交给机器人后单独开启辅助，观察实际行为。TS 在浏览器内编译为 JS 后提交；检查通过不等于脚本能正确行动，热身或正式对局中的验证仍不可少。Snippet 面板尚未提供。

## 游戏界面布局

| 区域 | 当前显示 |
|---|---|
| 中央战场 | 当前视野中的机器人和炮弹，以及地图资源；普通视野半径 20m，实体墙遮挡视线 |
| 顶部中央 | 对局时间与阶段 |
| 左下角 | 放大的 HP / EN 数字和状态条 |
| 右下角 | 可见机器人列表、Uplink 引导进度、五张技能状态卡与键位 |
| 对局顶部操作区 | **文档（M）**、**编辑器（C）**、回放和音效；热身中的房主还能开始正式对局 |
| 右侧栏 | 文档在上、编辑器在下，可分别展开或收起；只开一个时占满侧栏，宽度与上下分栏可拖拽 |
| 音效菜单 | 在当前页面工具栏展开，调整音量或静音；不会常驻遮挡文档 |

手操跟随战场画布焦点：画布聚焦（点击或 `Tab`）时 WASD/鼠标/`Space`/`Enter` 聊天全部生效，面板开着也一样；焦点进入文档、编辑器或聊天时释放手操，游戏画面、服务器模拟和脚本继续运行。打开面板时焦点自动移入，关闭全部面板后焦点回到战场画布；**返回战场** 一次关闭两者。浏览器宽度不超过 760px 时，侧栏覆盖战场，返回按钮仍可用。入口页和大厅中的手册继续以全屏显示。

编辑器提供 JS/TS 语言切换、对应的语法与类型检查、Bot API 补全；点击 **提交到机器人** 或按 `Ctrl+Enter` / `Cmd+Enter` 发送代码，等待服务器成功回执后，再用独立的 **辅助 ON/OFF** 按钮开启辅助。只有已连接并完成同步的热身或正式对局允许提交，重连、同步及对局结束时禁用。

JS/TS 草稿分别按房间码和昵称保存在当前浏览器的 `localStorage`，刷新后保留；面板开关状态和文档路径通过 URL 恢复。刷新或开始新局不会自动提交代码。具体提交限制和示例见[写第一个 Bot](../code/bot-scripting.md)。

当前尚无 Snippet 或游戏内 AI 对话面板，HUD 也不显示 AI 配额或实时总分。

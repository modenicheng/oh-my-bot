# 操作与控制仲裁

本页面向手操玩家。读完即可上场：怎么动、怎么开火、以及"代码开着代码还在替你开车"时谁说了算。

## 手操

桌面键鼠，网页端操作：

- **移动**：`W` `A` `S` `D` 全向移动（底盘无转向概念，炮塔独立瞄准）。
- **瞄准**：鼠标指向即炮塔指向。
- **开火**：鼠标左键。射击间隔 250ms，**有效射程 16m**——16m 外弹丸虽能飞更远但精度衰减，别浪费弹药。
- **Dash**：`Shift`。位移约 4.8m，耗能 20，冷却 2.5s，无无敌帧——它是赶路和微调身位用的，不是闪避无敌技。
- **护盾**：按住 `Q`。减伤 65%，期间不可开火、移速约 80%。
- **交互（Uplink）**：`E` 或 `F`。靠近 Uplink 2.5m 内按键开始引导黑入（详见[游戏规则](game-rules.md#uplink-黑入)）。
- **手册**：按 `M` 打开，再按 `M` 返回原页面。大厅和对局内都有标有 `M` 的手册按钮。阅读期间手操输入停止，对局继续运行；返回后可继续操作。

## 驾驶辅助（Snippet）

不写代码也能获得程序帮助：打开编辑器里的 Snippet 面板，逐条开关官方驾驶辅助：

| Snippet | 作用 | 参数（各 1–2 个） |
|---|---|---|
| 自动瞄准 | 炮塔自动追敌 | 提前量开关 |
| 自动开火 | 敌人进入射程自动开炮 | 射程阈值 |
| 自动拾取 | 自动去捡附近的 Core | 拾取半径 |
| 紧急护盾 | 危险时自动开盾 | HP 阈值 |
| 危险规避 | 自动躲开炮弹威胁 | 威胁半径 |
| 简单巡逻 | 沿路径点游走 | 路径点列表 |

Snippet 是官方维护的 Bot Script 模块，编辑器里可查看源码——想学写代码时它们就是教材。

## 分轴仲裁：人和程序如何并存

开了 Snippet 或脚本后，控制权按**控制轴**独立仲裁，共四轴：**移动 / 炮塔 / 开火 / 技能**。

规则只有一条：**你的输入随时优先，按轴抢占。**

- 你按 WASD 的瞬间，移动轴立刻归你，炮塔轴可能仍由"自动瞄准"控制——"WASD 手操 + 自动瞄准"并存是核心体验。
- 未被你抢占的轴，继续由 Snippet / Bot Script 控制。
- **抢占后不自动归还**。想整体交还给程序，用 Space 开关显式切换。

## Space 开关（驾驶辅助总开关）

- **按 `Space`**：切换驾驶辅助总开关——关（全手操）↔ 开（未被你占用的轴交还给程序）。备用键 `Enter` 旁的方案已定为 Space（备用 Enter）。
- 状态持久保留，不会因为你松开键盘就自动交还控制权。
- 编辑器中 `self.control` 面板可查看各轴当前控制来源：human / script / snippet。

## 快捷键表

| 按键 | 功能 |
|---|---|
| `W` `A` `S` `D` | 全向移动 |
| 鼠标移动 | 炮塔瞄准 |
| 鼠标左键 | 开火（250ms 间隔，有效射程 16m） |
| `Shift` | Dash（耗能 20，CD 2.5s） |
| `Q` | 按住护盾（减伤 65%，不可开火） |
| `E` / `F` | 交互：Uplink 引导黑入 |
| `Space` / `Enter` | 驾驶辅助总开关 |
| `M` | 打开手册 / 返回原页面，也可点击手册按钮 |
| `Tab` | 在按钮和输入框之间移动焦点 |

> 表格对应当前客户端。文字输入时不触发游戏快捷键；编辑器、Snippet 开关面板、喊话输入框及 Pulse Scan 按键入口尚未开放。

## 死亡与复活期间的操作

- 阵亡后 **3s** 复活：期间无法操作，编辑器可正常打开改码，复活即 Hot Swap 生效。
- 复活点在**你所属扇区**的出生点，满血满能量。
- 复活自带无敌：**挂机不解除**；做出任意操作后 **4s** 解除（操作不叠加刷新，防止出生点对狙）。无敌期冲出去打或缩回来苟，都是合法策略。

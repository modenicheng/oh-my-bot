# ADR-0013：复活无敌攻击破除 + Uplink 每玩家独立 CD + 弹丸射程硬顶

复审三项机制裁决（docs/design/reviews/2026-09-29-gpt6-astra-audit.md 发现 #1/#2/#3）：

1. **复活无敌**：挂机不解除不变；任意操作后 4s 解除不变；**开火或 interact() 立即解除无敌**——堵死 16 次受保护开火窗口，恢复"防出生点对狙"的本意。
2. **Uplink 防刷分重设计**：引导时长 1.5s → **8s**（争夺窗口从"路过顺手"变为"需守点决策"）；全局冷却改为**每玩家每桩独立 30s CD**（A 黑完 B 立即可黑同一桩——鼓励争夺而非串行排队；A 自己 30s 内不能再黑同一桩——封死单人循环刷分）。原"受击不打断、开火打断"引导规则不变。
3. **弹丸最大飞行距离硬顶 20m（= 视野半径）**：兑现"看得见才打得到"的公平承诺；16m 内精度衰减不变，16–20m 为衰减区，20m 绝对消亡。

放弃了全局 Uplink CD 方案（串行排队体验差）与分数递减方案（规则不透明）。

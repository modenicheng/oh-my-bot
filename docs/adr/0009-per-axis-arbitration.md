# 分轴控制仲裁与显式归还

驾驶辅助每局默认关闭，玩家显式按 Space（备用 Enter）开启；刷新重连恢复服务器上的当前状态。人类输入按 Axis（移动/炮塔/开火/技能）即时抢占程序控制，未被抢占的轴由 Bot Script/Snippet 继续控制，实现"WASD 手操 + 自动瞄准"并存的核心体验。抢占后不自动归还：玩家以快捷键（Space，备用 Enter）切换驾驶辅助总开关，显式完成交还/接管。放弃了单一总开关方案（粒度不足，人工程序拉锯）；v1 亦不向脚本暴露手操状态（playerDriving 不可见），保持玩家决策的最终隐私层。

修订（2026-10-03）：新增炮塔轴客户端采样例外——辅助开启且炮塔轴来源为脚本/官方 Snippet 且人未持有时，鼠标移动不置位 aim 轴（否则"开自瞄但手动开火"的玩家每次点击微动都会打断辅助瞄准），改按 `R` 显式夺取；HUD 在鼠标被吞时提示按 R、R 后提示 Space 交回。服务端仲裁语义与 ClientInput 协议不变：R 只是客户端把该轴重新纳入人类抢占的显式入口。旧服务器（无分轴来源字段）不启用，保持逐帧鼠标抢占。

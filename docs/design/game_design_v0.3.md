# oh-my-bot 游戏设计文档 v0.3

> 本版是当前设计基准（design of record），由 v0.2 经 2025-05 设计评审（grilling 会话 Round 1~5）修订而成。
> v0.1 / v0.2 保留于 `docs/design/` 仅作历史；冲突处一律以本文为准。
> 术语以根目录 `CONTEXT.md` 为准；关键决策依据见 `docs/adr/`。

---

## 1. 定位与总则

**64 人实时机器人派对大乱斗**：小组织内部破冰活动，私有部署，无公开服务计划。任何人手操入场（WASD + 鼠标），随后按自己的节奏把机器人逐步交给 Snippet、AI Agent 或自写代码——编程抬高天花板，但绝不是入场门槛。

三条铁律：

1. **一局内基础规则不变**：8 分钟内 move/fire/shield/scan/dash 的规则与数值全程稳定，只在 4:00 转段开放中央区域（ADR-0003）。
2. **感知免费、服务器代劳**：Observation 由服务器持续计算，`scan()` 零成本读取（ADR-0004）。
3. **人类输入随时优先**：控制权仲裁永远偏向手操玩家（ADR-0009）。

## 2. 对局结构

```
Room（房间，房主创建/邀请）
 ├─ Warmup（热身场）：开赛前任意漫游全图、编辑代码、配置 Snippet，无计分无死亡
 └─ Match（对局）×N —— Session（场次）：局散房不散，累计积分
     ├─ 0:00–4:00  OUTER_RING   外环争夺
     └─ 4:00–8:00  CORE_OPEN   核心解锁（中央区开放，仅此而已，规则不变）
```

- 房间人数 1–64（1 人 = 房主单人试跑，合法）；房主权限：开始 / 提前终止 / 重开。
- 地图种子在"开始"时生成，写入事件日志（回放可复现），房间内公开。
- 无观战位；无公开匹配、无账号——进房填昵称 + 选配色即入场。

## 3. 地图

- **八辐轮盘**骨架 + **三环**拓扑固定：外环（半径 55–80m，8 个出生扇区 Sector）、中环（30–55m）、中央核心区（<30m，4:00 前锁闭）；参考 160×160m。
- 骨架内的墙段、掩体、刷新点布局按**种子随机**生成；骨架与拓扑永不变化。
- 障碍 v1 只有**实体墙**：挡机器人、挡炮弹、挡视线。
- 人数 <64 时开局将 N 人**均分**到 8 个扇区（如 24 人 = 每扇区 3 人）。
- **Uplink**：中环 6 个，与扇区轴线错位 22.5° 布置；中央主 Uplink 与 4:00 转段同时激活。

## 4. 机器人规格（冻结基线，标注★的为待调默认值）

| 项 | 值 |
|---|---|
| 底盘 | 全向移动 + 独立炮塔，无转向概念（ADR-0005） |
| 移动 | 速度 8 m/s，加速度 24 m/s²，半径 0.6m；机器人间软碰撞，撞墙硬碰撞 |
| Dash | 耗能 20，CD 2.5s，持续 0.30s ≈ 16 m/s（位移 ≈4.8m），无无敌帧 |
| HP | 100；弹药伤害 12（≈9 发击毁） |
| 射击 | 弹丸初速 28–32 m/s★，射击间隔 250ms，**有效射程 16m**（弹丸可飞 24m+，16m 外精度衰减） |
| 能量 | 上限 100，回复 10/s；开火 5/发；护盾 ≈18/s；pulseScan 12 |
| 护盾 | 减伤 65%，不可开火，移速 ≈80% |
| 视野 | **20m**（≥ 有效射程：先看见、可反应、死亡可归因；搭档除外，见 §7） |
| pulseScan | 半径 32m，CD 2s，耗能 12，不穿墙 |

## 5. 感知系统

- 服务器为每台机器人按 60Hz 持续计算 **Observation**：视野半径 + 墙体遮挡裁剪后的可见实体集合。
- `scan()` 免费读取最近一份快照，可任意频次调用。
- `pulseScan()` 是耗能的主动增强感知，仍不穿墙。

## 6. 得分与目标

| 行为 | 得分 |
|---|---|
| 拾取 Core | +10（中央区更密，含 Mega Core ★+25） |
| 黑入 Uplink | +15（主 Uplink +25） |
| 击毁 | +25 |
| 助攻（击杀者的搭档） | +10 |
| 每次命中 | +1 |

- 目标分权重显著高于击杀分，防止退化成纯死斗；死亡**不掉分**（惩罚 = 3s 离场 + 对手得分）。
- **Uplink 玩法循环**：靠近（2.5m）→ `interact()` 引导 1.5s → 得分 → 冷却 **5s** → 任何人可再黑。引导规则：移出半径取消；**受击不取消**（可开盾硬黑）；开火取消；死亡取消。
- Core 由确定性刷新点（Spawn Pad）生成，4:00 后权重向中央偏移。
- **平局判定**：Uplink 得分 → 击毁数 → 存活时间 → 仍平则并列。

## 7. 搭档（Partner）

- 开局随机配对、整局固定、不可互伤、共享助攻。
- **视野规则唯一例外**：搭档隔墙可见（实体描边 + `scan()` 中恒带 `isPartner` 标记，不受视野半径限制）——无互伤所以无竞技危害，纯协作馈赠。
- 奇数人数默认：最后一人无搭档，`partner()` 返回 null（待实测调整）。

## 8. 复活与无敌

- 死亡 → 3s → 回**本扇区**出生点，满血满能量（防能量雪球；击杀者状态与复活状态无关）。
- 无敌规则：**挂机不解除**；做出任意操作后 4s 解除（操作不叠加刷新，防出生点对狙）。

## 9. 控制体系

四层控制，逐级进阶：

1. **手操**：WASD 移动 + 鼠标瞄准/射击（网页端唯一 v1 目标平台，桌面键鼠）。
2. **Snippet 驾驶辅助**：官方预置行为组件（本质是官方 Bot Script 模块，可查看源码当教材）。v1 六条定稿，每条 1–2 个参数：
   - 自动瞄准（提前量开关）/ 自动开火（射程阈值）/ 自动拾取（拾取半径）/ 紧急护盾（HP 阈值）/ 危险规避（威胁半径）/ 简单巡逻（路径点）。
3. **Bot Script**：玩家自写 JS/TS（唯一脚本语言，ADR-0002）。
4. **AI Agent**：平台内嵌代理，自然语言 → 改本玩家代码 → 热更生效（ADR-0010）。

**控制仲裁（ADR-0009）**：按 **Axis 控制轴**（移动 / 炮塔 / 开火 / 技能）独立仲裁；玩家输入即时**抢占**对应轴，未被抢占的轴由程序继续控制（WASD 手操 + 自动瞄准并存）。抢占后不自动归还，按 **Space**（备用 Enter）切换驾驶辅助总开关显式交还。v1 脚本不可感知手操状态。

**Hot Swap**：整局任意时刻可提交新版脚本，下一 tick 生效；提交失败（编译错/超配额）旧版继续跑。编辑器（Monaco）本地做 lint + 类型检查，行为验证靠热更——不做浏览器端完整模拟器。

## 10. 脚本运行时

- 60Hz 单时钟：模拟、脚本 tick、Observation、网络快照全部同频（ADR-0007）。
- goja 沙箱（ADR-0002），模块级状态跨 tick 存活。
- 配额：单 tick 默认 **10ms**（可配置），超时 goja interrupt 强制中断、该 tick 机器人 idle 并计入异常统计。配额是防死循环的正确性机制，非性能预算（典型脚本远低于此）。
- **AI Agent 配额（双轨）**：每玩家每局 **20 轮提示**（Agent 自身工具调用不计轮次）+ **300k token**；走平台 AIProvider 代理（首个实现：DeepSeek 官方 API deepseek-chat，token 计量读 usage 字段），只可访问本玩家代码与感知数据。两者均写事件日志，供称号投影。

## 11. 脚本 API（L0 原语 + L1 便利，到此为止）

```ts
// L0 原语
move(vx, vy); aimAt(angle); fire(); dash(); shield(on); interact(); say(text) // 3s 冷却，自由文本
// L1 便利
moveTo(pos); aimAt(entity); nearestEnemy(); nearestCore(); nearestUplink(); partner()
// 感知与环境
scan();              // → Observation（可见 robots / cores / uplinks / projectiles）
game.time; game.timeLeft; game.phase;   // "OUTER_RING" | "CORE_OPEN"
self.hp; self.energy; self.position;
```

**不提供**（这是玩家要自己写的天花板）：寻路、弹道预测、威胁评估。v0.1 的 `turn/turnTo` 随全向底盘删除。

## 12. 技术架构

- **server/**：Go 单权威节点，60Hz 定频模拟（ADR-0001）；事件溯源——模拟只产事件，统计皆投影（ADR-0006）；JSONL 按局归档。
- **client/**：TS + PixiJS 60fps 渲染；WS + protobuf 二进制；60Hz 快照；自机移动客户端预测 + 输入序列号和解，射击不预测。
- **bot-api/**：TS 类型定义包，玩家与 AI 共用。
- **protocol/**：WS 消息契约。
- **回放**：客户端内置（非独立工具）：时间轴拖动、任意机器人视角、0.5/1/2/4× 倍速，全程从事件日志投影。
- **部署**：单 Go 二进制（embed 前端静态资源），事件日志落盘 JSONL，无数据库；内网任意机器跑起即用。
- **手册**：`docs/manual/` Markdown 双受众——人类的上手/操作/编程指南，同时是 AI Agent 语料；客户端用现成渲染库内置 MD 阅读器（ADR-0011）。

## 13. 结算与称号

结算页先全局战报（炮弹总数 / 撞墙总数 / AI 改码总数…），再称号，最后总分。**13 个称号**从事件日志投影：

| 称号 | 判定 |
|---|---|
| 战争机器 | 击毁最多 |
| 垃圾佬 | Core 拾取最多 |
| 信号大盗 | Uplink 黑入最多 |
| 跑路大师 | 移动距离最长 |
| 铁头娃 | 撞墙最多 |
| 苟王 | 最长连续存活 |
| 和平使者 | 高积分零击毁 |
| 人工智障 | 脚本异常/超时最多 |
| 弹幕大师 | 射击最多 |
| 最佳搭档 | 搭档协作得分最高 |
| AI 常客 | AI 改码轮次最多 |
| 古法编程 | 零 AI 零 Snippet 完赛 |
| 充能面包 | 被击毁最多（CNMB） |

烧 token 大户以数值展示于结算页（AI 轮次 / token 用量人人可见），不占称号位。Session 累计积分榜随每局更新。

## 14. v1 明确不做

公开匹配 / 账号系统 / 移动端 / Drone 补位 / 观战位 / 内容审核（互信群体）/ 规模化反作弊 / 装备·职业·科技树 / 阶段变规则 / 寻路预测等高层 API / 浏览器端完整模拟器 / 跨房间持久数据。

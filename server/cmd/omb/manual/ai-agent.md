# AI Agent 攻略

不想手写代码？让平台内嵌的 AI Agent 替你改。它把自然语言指令变成对你 Bot Script 的修改，热更后立即生效。

## 它是什么、能碰什么

- **入口**：编辑器内的 AI Agent 面板，用中文/英文自然语言下指令。
- **权限边界**：Agent 只能访问**本玩家**的代码与感知数据——看不到别人的脚本，改不了别人的机器人。
- **不自带 key**：所有外部大模型调用经平台侧 AIProvider 代理接入（首个实现：DeepSeek `deepseek-chat`），计量由平台完成，你只管提需求。

## 怎么用：三步循环

1. **说需求**：例如"敌人进 14m 就开火，残血 30 以下开盾撤退"。
2. **Agent 改码**：它读取你的 Bot Script 与类型定义（就是本手册引用的 `@omb/bot-api` 签名），生成新版本。
3. **热更生效**：修改经 Hot Swap 提交，下一 tick 上场；改坏了（编译错/超配额）旧版本继续跑，不会当场趴窝。

指令越具体越好。对照[游戏规则](game-rules.md)里的数值提需求：有效射程 16m（弹丸 20m 硬顶）、Uplink 引导 8s、个人 CD 30s、能量回复 10/s——说"敌人在 16m 内才开火"比"帮我打得准点"有效得多。

## 双轨配额：20 轮 + 300k token

每玩家每局，两条额度独立计：

| 轨道 | 额度 | 计法 |
|---|---|---|
| 提示轮次 | **20 轮/局** | 你发出的一次指令算一轮；**Agent 自身的工具调用（读文件、改码等）不计轮次** |
| Token | **300k token/局** | 按模型响应的 usage 字段累加 |

全局护栏：**单局全员合计 2M token**，触顶后全员禁 AI（提示"本局 AI 额度已尽"）；全局并发 20 请求；热身场消耗同一配额池。

- 两项配额均写入对局事件日志，可回溯审计。
- 用完 20 轮不等于游戏结束：脚本照跑，你还能手操、手写码、调 Snippet；下一局配额重置。
- 配额按局计，热身场与正式局的计法以客户端配额显示为准。

## 配额怎么花得值

- **一轮一个明确目标**："加自动拾取 Core"是一轮，"把整个机器人做强"也是一轮——前者大概率成，后者容易废。
- **让 Snippet 干粗活**：六条官方驾驶辅助不花配额，先开 Snippet 打底，Agent 只做 Snippet 覆盖不了的定制逻辑。
- **改前留版本意识**：改坏了旧版兜底继续跑，但想要回到"三轮前那个手感"，用一轮指令描述回去，或干脆手抄一版。

## 称号相关

- **AI 常客**：本局 AI 改码轮次最多者。
- **古法编程**：**零 AI、零 Snippet 完赛**。全程手写（或纯手操）跑完整局才拿得到——开了一条 Snippet 就和它无缘。
- **人工智障**：脚本异常/超时最多。Agent 生成的代码一样吃 10ms/tick 配额，死循环脚本不管是谁写的都会中招。
- **烧 token 大户**：不占称号位，但 AI 轮次与 token 用量在结算页人人可见——烧得最凶的人会被全场记住。

## 和其他路径的关系

- **手操 + Snippet**（零代码，见[操作](controls.md)）→ **AI 改码**（本页）→ **手写 Bot Script**（见[编程指南](bot-scripting.md)）是三条渐进路径，可随时混用：开着自动瞄准 Snippet 的同时让 Agent 写巡逻逻辑，完全合法——控制仲裁会把各轴安排明白。
- 唯一的互斥是荣誉层面的：想要「古法编程」，本局就得一条 Snippet 不开、一轮 AI 不用。
